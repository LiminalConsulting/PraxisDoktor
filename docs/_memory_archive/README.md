# _memory_archive/

Snapshots von Claude-Auto-Memory-Einträgen, die ursprünglich
projektspezifisches PraxisDoktor-Wissen enthielten, aber in der
token-teuren globalen Auto-Memory lagen.

Verschoben hierher am **2026-05-14** im Zuge der LiminalConsulting-
Repo-Reorganisation (jeder Klient hat jetzt sein eigenes `STATUS.md`;
projektspezifisches Wissen gehört ins Projekt-Repo, nicht in die
querschnittliche Memory).

Diese Dateien sind **point-in-time-Schnappschüsse** — sie spiegeln den
Stand zur Zeit ihrer Erstellung (April/Mai 2026), nicht den aktuellen
Stand. Für den aktuellen Stand siehe `../../STATUS.md` und die
kanonischen Dokumente in `../` (`regulatory_landscape.md`,
`processes_observed.md`, `process_ontology.md`, etc.).
